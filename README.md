# Rainwater Harvesting Feasibility Calculator & Recommender

**JNTUK B.Tech R23 Regulation - Semester 2 Mini-Project**

## 📖 Overview
An integrated engineering tool for assessing rainwater harvesting potential by combining principles of **Civil Hydrodynamics** and **Linear Algebra Matrix Solvers**.

## 🧮 Engineering Methodology
* **Rational Method Runoff Potential:**
  $$H = A \times R \times C \times E$$
  * **$A$**: Roof Catchment Area ($\text{m}^2$)
  * **$R$**: Annual Rainfall ($\text{mm}$)
  * **$C$**: Runoff Coefficient
  * **$E$**: Filter System Efficiency

## 📁 Repository Structure
* `main.py` - Core calculation engine & linear algebra solvers.
* `dashboard.py` - Output dashboard & results formatting.
